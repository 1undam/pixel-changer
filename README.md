# pixel-chager

AI가 그린 "픽셀 느낌" 그림이나 일반 이미지를 깨끗한 픽셀 아트로 바꾸는 브라우저 도구와, 그 도구를 Claude가 쓸 수 있게 묶은 스킬(`pixel-mosaic`)입니다.

A Claude skill (`pixel-mosaic`) that bundles a single-file browser tool for turning AI-generated or ordinary images into clean pixel art.

## 무엇을 하나요

AI 이미지 모델이 그린 도트 그림은 실제로는 격자에 맞지 않습니다. 픽셀 크기가 7~9px로 들쭉날쭉하고, 가장자리가 번지고, 비슷한 색이 수백 개입니다. 그대로 축소하면 뭉개집니다. 이 도구는 그림이 원래 의도한 격자를 찾아내고 칸마다 색을 하나씩 고릅니다.

- **격자 자동 감지**: 색이 바뀌는 경계를 세어 칸 크기와 시작 위치를 찾고, 선을 실제 경계에 맞춰 보정합니다.
- **배경 지우기**: 테두리에서 가장 많은 색을 배경으로 보고 지웁니다.
- **칸 색 고르기**: 가장 많은 색, 중앙값, 가운데 픽셀, 평균, 중심 가중 평균.
- **팔레트**: k-평균, OKLCH 묶기, 중앙 분할, 원래 색 유지. 모두 OKLab 색 공간 기준입니다.
- **정리**: 외톨이 픽셀 지우기, 1px 구멍 메우기.
- **색 빼기와 고정 색**: 다시 계산하지 않고 해당 칸만 바꿉니다.
- **색 판정**: 칸을 누르면 색이 단계별로 어떻게 정해졌는지 보여줍니다.
- **직접 편집**: 칠하기, 지우개, 스포이드, 되돌리기.
- **PNG 내보내기**: 1배에서 16배.

설치나 빌드가 필요 없고, 이미지는 어디에도 업로드되지 않습니다.

## 시작하기

### 도구만 쓰기

[`pixel-mosaic/assets/pixel-mosaic.html`](pixel-mosaic/assets/pixel-mosaic.html) 파일을 내려받아 브라우저에서 엽니다. 인터넷 연결 없이도 동작합니다.

### Claude 스킬로 설치

`pixel-mosaic` 폴더를 스킬 폴더에 복사합니다.

| 범위 | 위치 |
|---|---|
| 내 모든 프로젝트 | `~/.claude/skills/pixel-mosaic/` |
| 한 프로젝트만 | `<프로젝트>/.claude/skills/pixel-mosaic/` |

설치하면 "이 그림 도트로 바꿔줘" 같은 요청에 Claude가 이 도구를 꺼내 쓰고, 변환이 이상할 때 어떤 값을 바꿔야 하는지 안내합니다.

## 사용 설명서

### 1. 이미지 넣기

세 가지 방법이 있습니다.

- 상단의 **이미지 열기** 버튼
- 화면 아무 곳에서나 **Ctrl+V** 붙여넣기
- 이미지 파일을 화면에 **끌어다 놓기**

이미지를 넣으면 바로 변환됩니다. 처음 열면 예시 그림이 들어 있어 동작을 먼저 볼 수 있습니다.

### 2. 화면 보는 법

| 영역 | 내용 |
|---|---|
| 왼쪽 **결과** | 변환된 픽셀 아트. 모든 픽셀이 같은 크기로 그려집니다. |
| 오른쪽 **원본** | 원본 위에 찾아낸 칸 경계가 그려집니다. 선이 고르지 않은 것은 실제 색 경계를 따라가기 때문입니다. |
| 왼쪽 **설정** 칸 | 1~5단계 설정. ⚙ 설정 버튼으로 접고 펼칩니다. |
| 아래 **색** | 결과에 쓰인 색 견본 |
| 아래 **색 판정** | 누른 칸의 색이 정해진 과정 |
| 아래 **내보내기** | PNG 만들기 |

**잘 됐는지 확인하는 법**: 원본 쪽 격자선이 색 덩어리의 테두리 위에 놓여 있으면 맞게 찾은 것입니다. 오른쪽 위 상태 줄의 **경계 일치 %** 가 30% 이상이면 대체로 정상입니다.

두 화면은 확대와 이동이 함께 움직이고, 한쪽에서 칸을 누르면 다른 쪽의 대응하는 칸도 표시됩니다.

### 3. 설정 단계

설정은 위에서 아래 순서로 적용됩니다. **값 바꾸면 자동** 이 켜져 있으면 값을 바꾸는 즉시 다시 변환하고, 꺼져 있으면 **▶ 정리하기** 를 눌러야 반영됩니다.

**1단계. 배경 지우기**

| 설정 | 설명 |
|---|---|
| 방식 | 자동이면 테두리에서 가장 많은 색을 배경으로 보고 지웁니다. |
| 허용 오차 | 배경색과 얼마나 달라도 배경으로 볼지. 배경이 남으면 올리고, 그림이 지워지면 내립니다. |
| 테두리와 이어진 배경만 | 켜 두면 그림 안쪽에 있는 같은 색(눈동자, 외곽선)은 남습니다. |

원래 투명한 PNG는 그 투명도를 그대로 씁니다.

**2단계. 픽셀 격자**

| 설정 | 설명 |
|---|---|
| 칸 크기 기준 | **자동**: 색 경계로 찾습니다. **수동**: 칸 크기와 오프셋을 직접 넣습니다. **결과 크기 고정**: 64×64처럼 결과 크기를 정합니다. |
| 찾을 칸 크기 범위 | 도트 하나가 원본의 몇 px일지 후보 범위. 엉뚱한 크기를 고르면 범위를 좁힙니다. |
| 색 경계로 볼 차이 | 옆 픽셀과 색이 얼마나 달라야 경계로 셀지. 잡티가 많으면 올리고, 파스텔처럼 대비가 약하면 15~20으로 내립니다. |
| 칸 경계를 실제 색 경계에 맞춤 | 등간격 선을 근처의 실제 경계로 옮깁니다. 도트 크기가 고르지 않은 AI 그림에 필요합니다. |
| 최대 이동 | 선 하나가 옮겨질 수 있는 최대 거리. 칸 크기의 %입니다. |
| 찾은 값을 수동으로 | 자동으로 찾은 값을 수동 칸에 옮겨 미세 조정할 때 씁니다. |

**3단계. 칸 색 고르기**

| 설정 | 설명 |
|---|---|
| 방식 | 기본값 **살짝 모은 뒤 가장 많은 색** 은 칸 안에서 가장 넓은 색을 고릅니다. 평균은 색이 섞여 탁해질 수 있습니다. |
| 색 묶기 간격 | 얼마나 비슷한 색을 같은 색으로 셀지 |
| 칸 테두리 무시 | 칸 가장자리의 번진 픽셀을 빼고 봅니다. 색이 탁하면 올립니다. |
| 투명 기준 | 칸에서 그림이 차지하는 비율이 이보다 낮으면 투명으로 둡니다. |

**4단계. 팔레트**

| 설정 | 설명 |
|---|---|
| 방식 | **k-평균**: 색 수를 직접 정합니다. **OKLCH 묶기**: 비슷한 색끼리 묶어 색 수가 자동으로 정해집니다. **원래 색 유지**: 색을 줄이지 않습니다. |
| 색 수 | 결과에 쓸 색 개수 |
| 팔레트 색 | **원본 색** 은 그림에 실제로 있던 색을 씁니다. **평균 색** 은 묶음의 평균을 씁니다. |
| 색 거리, 색상 무게 | 가까운 색을 고를 때 색상 차이를 얼마나 크게 볼지 |
| 명암 계열 우선 | 같은 색의 밝고 어두운 칠을 다른 색상보다 먼저 고릅니다. 그늘이 엉뚱한 색이 되는 것을 막습니다. |
| 어두운 색을 외곽선 색 하나로 | 검정에 가까운 색들을 하나로 모읍니다. |

**5단계. 정리**

| 설정 | 설명 |
|---|---|
| 외톨이 픽셀 지우기 | 주변과 다른 한 칸짜리 점을 지웁니다. 대비가 큰 점(눈동자)은 남깁니다. |
| 1px 구멍 메우기 | 사방이 막힌 투명 한 칸을 채웁니다. |

### 4. 색 다루기

아래 **색** 견본 줄에서 합니다.

- **쓰인 곳 보기**: 견본이나 결과 픽셀을 좌클릭하면 그 색이 쓰인 칸만 잠깐 밝게 표시됩니다.
- **색 빼기**: 견본이나 결과 픽셀을 우클릭합니다. 그 색이던 칸만 가장 가까운 남은 색으로 바뀌고 나머지는 그대로입니다. 다시 우클릭하거나 **모두 되살리기** 로 되돌립니다.
- **고정 색 추가**: 견본 줄 끝의 **+** 를 누른 뒤 원본 화면의 칸을 클릭합니다. 그 칸의 색이 파란 테두리의 고정 색으로 들어갑니다. 팔레트에서 빠진 작은 포인트 색을 살릴 때 씁니다. Shift+클릭이면 계속 고르고, Esc로 그만둡니다. 고정 색 견본을 우클릭하면 해제됩니다.

### 5. 색 판정 보기

**선택** 도구에서 결과 픽셀이나 원본 칸을 클릭하면 아래 **색 판정** 에 다음이 나옵니다.

- 칸 색 → 팔레트 → 정리 → 색 빼기 → 고정 색 → 직접 지정 순으로, 각 단계에서 정해진 색
- 가장 가까운 팔레트 색 세 개와 거리
- 칸 안의 색 분포
- **직접 지정**: 견본을 눌러 그 칸만 원하는 색이나 투명으로 바꾸기

"왜 이 칸이 이 색이 됐는지"를 확인하고 어떤 설정을 고칠지 정할 때 씁니다.

### 6. 직접 고치기

상단의 도구를 바꿔서 결과를 직접 편집합니다.

| 도구 | 동작 |
|---|---|
| **선택** | 칸을 눌러 색 판정 보기, 끌어서 화면 이동 |
| **칠하기** | 색 견본을 눌러 붓 색을 고른 뒤, 결과 칸을 누르거나 끌어서 칠합니다. |
| **지우개** | 결과 칸을 투명으로 만듭니다. |
| **되돌리기** | 한 획씩 취소합니다. Ctrl+Z도 됩니다. |

칠하기나 지우개 중에 결과 칸을 **우클릭** 하면 그 칸의 색이 붓 색이 됩니다.

직접 고친 칸은 설정을 바꿔 다시 변환해도 남습니다. 결과 크기가 달라지면 초기화됩니다.

### 7. 조작 정리

| 동작 | 마우스 | 터치 |
|---|---|---|
| 확대, 축소 | 휠 | 두 손가락 벌리기 |
| 화면 이동 | 선택 도구에서 드래그, 또는 휠버튼 드래그 | 두 손가락 드래그 |
| 화면에 맞추기 | 화면 맞춤 버튼, 또는 더블클릭 | 화면 맞춤 버튼 |
| 색 추출 | 칠하기 중 우클릭 | 길게 누르기 |
| 색 빼기 | 선택 도구에서 우클릭 | 견본에서만 가능 |
| 격자 숨기기 | 격자 체크 해제 | 같음 |

### 8. 내보내기

아래 **내보내기** 에서 배율을 고르고 **PNG 만들기** 를 누릅니다. ×1은 결과 픽셀 그대로이고, ×8이면 픽셀 하나가 8×8로 커집니다. 뜬 이미지를 우클릭해 저장하거나 **클립보드로 복사** 를 누릅니다.

게임 엔진에 넣을 스프라이트는 ×1로 내보내고 엔진에서 필터를 Point로 설정하는 것이 좋습니다.

### 9. 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 결과가 큰 덩어리 몇 개뿐이거나, 너무 잘게 쪼개짐 | **찾을 칸 크기 범위** 를 실제 도트 크기 근처로 좁힙니다. |
| 격자선이 색 덩어리와 어긋남 | **색 경계로 볼 차이** 를 조절합니다. 잡티가 많으면 올리고 대비가 약하면 내립니다. |
| 대부분 맞는데 몇 칸만 반쪽 크기 | **최대 이동** 을 낮추거나 **칸 경계를 실제 색 경계에 맞춤** 을 끕니다. |
| 자동으로 계속 못 찾음 | **칸 크기 기준** 을 수동이나 결과 크기 고정으로 바꿉니다. 사진처럼 격자가 없는 그림은 결과 크기 고정이 맞습니다. |
| 배경이 남음, 또는 그림 일부가 사라짐 | **허용 오차** 를 조절합니다. |
| 칸 경계 쪽 색이 탁함 | **칸 테두리 무시** 를 올립니다. |
| 작은 포인트 색이 사라짐 | **+** 로 그 색을 고정 색으로 추가합니다. |
| 그늘이 다른 색상으로 바뀜 | **명암 계열 우선** 을 켜거나 **색상 무게** 를 올립니다. |
| 점처럼 튀는 픽셀이 남음 | 5단계의 **외톨이 픽셀 지우기** 를 켭니다. |

## 없는 기능

프리셋 후보 비교와 점수, 자동 최적화, 외곽선 1px 맞추기, 스프라이트 시트 프레임 나누기, 디더링, 일괄 변환은 없습니다. 긴 쪽이 1600px을 넘는 이미지는 불러올 때 축소됩니다.
