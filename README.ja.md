# pixel-changer

[한국어](README.md) | [English](README.en.md) | **日本語**

AIが描いた「ドット風」の絵や普通の画像を、きれいなピクセルアートに変換するブラウザツールです。Claudeが使えるようにスキル(`pixel-changer`)としてまとめてあります。

## できること

画像生成AIが描くドット絵は、実際にはグリッドに沿っていません。ピクセルの幅が7〜9pxとばらつき、輪郭はにじみ、よく似た色が数百色もあります。そのまま縮小するとつぶれてしまいます。このツールは、絵が本来意図していたグリッドを見つけ出し、マスごとに色を1つ選びます。

- **グリッド自動検出**: 色が変わる境界を数えてマスの大きさと開始位置を求め、線を実際の境界に合わせて補正します。
- **背景の除去**: 画像の縁で最も多い色を背景とみなして消します。
- **マスの色の決定**: 最も多い色、中央値、中心ピクセル、平均、中心加重平均。
- **パレット**: k平均法、OKLCHグルーピング、メディアンカット、元の色を維持。いずれもOKLab色空間で計算します。
- **仕上げ**: 孤立ピクセルの除去、1pxの穴埋め。
- **色の除外と固定色**: 再計算せず、該当するマスだけを変えます。
- **色の判定**: マスをクリックすると、色が決まった過程を段階ごとに表示します。
- **手動編集**: 塗る、消しゴム、スポイト、元に戻す。
- **PNG書き出し**: 1倍から16倍。

インストールもビルドも不要で、画像はどこにもアップロードされません。

> ツールの画面は韓国語です。この説明では、韓国語のラベルに意味を添えて記載します。

## はじめに

### ツールだけを使う

[`pixel-changer/assets/pixel-changer.html`](pixel-changer/assets/pixel-changer.html) をダウンロードしてブラウザで開きます。インターネット接続がなくても動作します。

### Claudeスキルとしてインストール

`pixel-changer` フォルダをスキルフォルダにコピーします。

| 範囲 | 場所 |
|---|---|
| すべてのプロジェクト | `~/.claude/skills/pixel-changer/` |
| 1つのプロジェクトのみ | `<プロジェクト>/.claude/skills/pixel-changer/` |

インストールすると、「この絵をドット絵にして」といった依頼でClaudeがこのツールを取り出し、変換がうまくいかないときにどの値を変えればよいかを案内します。

## 使い方

### 1. 画像を読み込む

方法は3つあります。

- 上部の **이미지 열기**(画像を開く)ボタン
- 画面のどこでも **Ctrl+V** で貼り付け
- 画像ファイルを画面に **ドラッグ&ドロップ**

読み込むとすぐに変換されます。最初に開いたときはサンプル画像が入っているので、先に動作を確認できます。

### 2. 画面の見方

| 領域 | 内容 |
|---|---|
| 左 **결과**(結果) | 変換されたピクセルアート。すべてのピクセルが同じ大きさで描かれます。 |
| 右 **원본**(元画像) | 元画像の上に、検出したマスの境界が描かれます。線が不揃いなのは、実際の色の境界に沿っているためです。 |
| 左の列 **설정**(設定) | 1〜5段階の設定。⚙ 설정 ボタンで開閉します。 |
| 下 **색**(色) | 結果で使われている色の見本 |
| 下 **색 판정**(色の判定) | クリックしたマスの色が決まった過程 |
| 下 **내보내기**(書き出し) | PNGの作成 |

**うまくいったかの確認方法**: 元画像側のグリッド線が色のかたまりの縁に重なっていれば、正しく検出できています。右上のステータス行に表示される **경계 일치 %**(境界一致率)が30%以上なら、おおむね正常です。

2つの画面は拡大と移動が連動します。片方でマスをクリックすると、もう片方の対応するマスも表示されます。

### 3. 設定の各段階

設定は上から順に適用されます。**값 바꾸면 자동**(値を変えたら自動)にチェックが入っていれば、値を変えた時点で再変換されます。外している場合は **▶ 정리하기**(整理する)を押すと反映されます。

**第1段階 배경 지우기(背景の除去)**

| 設定 | 説明 |
|---|---|
| 방식(方式) | 자동(自動)では、縁で最も多い色を背景とみなして消します。 |
| 허용 오차(許容誤差) | 背景色とどれだけ違っても背景とみなすか。背景が残るなら上げ、絵が消えるなら下げます。 |
| 테두리와 이어진 배경만(縁につながった背景のみ) | オンにすると、絵の内側にある同じ色(瞳や輪郭線)は残ります。 |

もともと透明なPNGは、その透明度をそのまま使います。

**第2段階 픽셀 격자(ピクセルグリッド)**

| 設定 | 説明 |
|---|---|
| 칸 크기 기준(マスの大きさの基準) | **자동**(自動): 色の境界から求めます。**수동**(手動): マスの大きさとオフセットを直接入力します。**결과 크기 고정**(出力サイズ固定): 64×64のように出力サイズを指定します。 |
| 찾을 칸 크기 범위(探すマスの大きさの範囲) | ドット1つが元画像の何pxにあたるかの候補範囲。見当違いの大きさが選ばれるときは範囲を狭めます。 |
| 색 경계로 볼 차이(色の境界とみなす差) | 隣のピクセルと色がどれだけ違えば境界として数えるか。ノイズが多ければ上げ、パステル調のようにコントラストが弱ければ15〜20に下げます。 |
| 칸 경계를 실제 색 경계에 맞춤(マスの境界を実際の色の境界に合わせる) | 等間隔の線を近くの実際の境界へ移動します。ドットの大きさが不揃いなAI画像に必要です。 |
| 최대 이동(最大移動量) | 線1本が動ける最大距離。マスの大きさに対する%です。 |
| 찾은 값을 수동으로(検出値を手動へ) | 自動で求めた値を手動欄に移し、微調整するときに使います。 |

**第3段階 칸 색 고르기(マスの色の決定)**

| 設定 | 説明 |
|---|---|
| 방식(方式) | 既定の **살짝 모은 뒤 가장 많은 색**(軽くまとめてから最も多い色)は、マスの中で最も広い色を選びます。平均は色が混ざってくすむことがあります。 |
| 색 묶기 간격(色をまとめる間隔) | どれだけ似た色を同じ色として数えるか |
| 칸 테두리 무시(マスの縁を無視) | マスの縁のにじんだピクセルを除いて判定します。色がくすむときは上げます。 |
| 투명 기준(透明の基準) | マスの中で絵が占める割合がこれより低いと透明にします。 |

**第4段階 팔레트(パレット)**

| 設定 | 説明 |
|---|---|
| 방식(方式) | **k-평균**(k平均法): 色数を自分で決めます。**OKLCH 묶기**(OKLCHグルーピング): 似た色をまとめ、色数は自動で決まります。**원래 색 유지**(元の色を維持): 減色しません。 |
| 색 수(色数) | 結果で使う色の数 |
| 팔레트 색(パレットの色) | **원본 색**(元の色)は絵に実際にあった色を使います。**평균 색**(平均色)はグループの平均を使います。 |
| 색 거리, 색상 무게(色の距離、色相の重み) | 近い色を選ぶとき、色相の違いをどれだけ重く見るか |
| 명암 계열 우선(明暗の系統を優先) | 同じ色の明るい塗りと暗い塗りを、別の色相より先に選びます。影が見当違いの色になるのを防ぎます。 |
| 어두운 색을 외곽선 색 하나로(暗い色を輪郭線の1色に) | 黒に近い色を1つにまとめます。 |

**第5段階 정리(仕上げ)**

| 設定 | 説明 |
|---|---|
| 외톨이 픽셀 지우기(孤立ピクセルの除去) | 周囲と異なる1マスだけの点を消します。コントラストの強い点(瞳)は残します。 |
| 1px 구멍 메우기(1pxの穴埋め) | 四方を囲まれた透明な1マスを埋めます。 |

### 4. 色の操作

下の **색**(色)の見本の列で行います。

- **使われている場所を見る**: 見本または結果のピクセルを左クリックすると、その色のマスだけがしばらく明るく表示されます。
- **色を除外する**: 見本または結果のピクセルを右クリックします。その色だったマスだけが最も近い残りの色に変わり、ほかはそのままです。もう一度右クリックするか、**모두 되살리기**(すべて戻す)で元に戻します。
- **固定色を追加する**: 列の末尾の **+** を押してから、元画像のマスをクリックします。そのマスの色が青い枠の固定色として加わります。パレットから落ちた小さなアクセント色を戻すときに使います。Shift+クリックで続けて選べ、Escで終了します。固定色の見本を右クリックすると解除されます。

### 5. 色の判定

**선택**(選択)ツールで結果のピクセルか元画像のマスをクリックすると、下の **색 판정** に次の内容が表示されます。

- マスの色 → パレット → 仕上げ → 色の除外 → 固定色 → 直接指定の順に、各段階で決まった色
- 最も近いパレットの色3つとその距離
- マスの中の色の分布
- **직접 지정**(直接指定): 見本を押して、そのマスだけを好きな色または透明に変更

「なぜこのマスがこの色になったのか」を確かめ、どの設定を直すかを決めるときに使います。

### 6. 手動で直す

上部のツールを切り替えて、結果を直接編集します。

| ツール | 動作 |
|---|---|
| **선택**(選択) | マスを押して色の判定を見る、ドラッグで画面を移動 |
| **칠하기**(塗る) | 色見本を押して筆の色を選び、結果のマスをクリックまたはドラッグして塗ります。 |
| **지우개**(消しゴム) | 結果のマスを透明にします。 |
| **되돌리기**(元に戻す) | 1ストロークずつ取り消します。Ctrl+Zでも可能です。 |

塗る、または消しゴムの使用中に結果のマスを **右クリック** すると、そのマスの色が筆の色になります。

手動で直したマスは、設定を変えて再変換しても残ります。出力サイズが変わると初期化されます。

### 7. 操作一覧

| 動作 | マウス | タッチ |
|---|---|---|
| 拡大、縮小 | ホイール | ピンチ |
| 画面の移動 | 選択ツールでドラッグ、またはホイールボタンでドラッグ | 2本指でドラッグ |
| 画面に合わせる | **화면 맞춤** ボタン、またはダブルクリック | **화면 맞춤** ボタン |
| 色の抽出 | 塗る途中で右クリック | 長押し |
| 色の除外 | 選択ツールで右クリック | 見本でのみ可能 |
| グリッドを隠す | **격자**(グリッド)のチェックを外す | 同じ |

### 8. 書き出し

下の **내보내기**(書き出し)で倍率を選び、**PNG 만들기**(PNGを作成)を押します。×1は結果のピクセルそのまま、×8ならピクセル1つが8×8になります。プレビューで **PNG 저장**(PNGを保存)を押すと、保存場所と名前を選ぶ画面が開きます。ファイル名は `元の名前_幅x高さ_x倍率.png` の形式で提案されます。**클립보드로 복사**(クリップボードにコピー)で、ほかのアプリにそのまま貼り付けることもできます。

ゲームエンジンで使うスプライトは、×1で書き出してエンジン側でフィルターをPointに設定するのがおすすめです。

### 9. うまくいかないとき

| 症状 | 対処 |
|---|---|
| 結果が大きなかたまり数個だけ、または細かく割れすぎる | **찾을 칸 크기 범위** を実際のドットの大きさの近くに狭めます。 |
| グリッド線が色のかたまりとずれる | **색 경계로 볼 차이** を調整します。ノイズが多ければ上げ、コントラストが弱ければ下げます。 |
| ほぼ合っているが、数マスだけ半分の幅になる | **최대 이동** を下げるか、**칸 경계를 실제 색 경계에 맞춤** をオフにします。 |
| 自動検出が失敗し続ける | **칸 크기 기준** を 수동 または 결과 크기 고정 に変えます。写真のようにグリッドのない画像には出力サイズ固定が向いています。 |
| 背景が残る、または絵の一部が消える | **허용 오차** を調整します。 |
| マスの境界付近の色がくすむ | **칸 테두리 무시** を上げます。 |
| 小さなアクセント色が消えた | **+** でその色を固定色として追加します。 |
| 影が別の色相に変わった | **명암 계열 우선** をオンにするか、**색상 무게** を上げます。 |
| 点のように目立つピクセルが残る | 第5段階の **외톨이 픽셀 지우기** をオンにします。 |

## 構成

```
pixel-changer/
├── SKILL.md                     スキルの説明と使用手順
├── assets/pixel-changer.html    ツール本体
└── references/pipeline.md       各段階のアルゴリズムの説明
```

各段階の計算方法は [`pixel-changer/references/pipeline.md`](pixel-changer/references/pipeline.md) にあります。

## ない機能

プリセット候補の比較とスコア、自動最適化、輪郭線の1px合わせ、スプライトシートのフレーム分割、ディザリング、一括変換はありません。長辺が1600pxを超える画像は、読み込み時に縮小されます。
